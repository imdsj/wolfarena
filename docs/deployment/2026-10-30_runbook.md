## 3. 部署前必须先备份

在服务器上执行（只读检查 + 备份，不删除任何文件）：

```bash
cd /path/to/wolfarena-source
bash deploy/backup-check.sh
# 若需要额外打包现有站点目录：
bash deploy/backup-check.sh /www/wwwroot/<现有站点目录>
```

脚本会在 `/www/backup/wolfarena-<时间戳>/` 生成：

- `system-info.txt`：内核、系统版本、`nginx -v`、`nginx -t`、Python/Node 版本、8001 端口占用情况
- `wwwroot-list.txt`：站点目录清单
- `nginx-config/`：nginx 配置副本
- `site.tar.gz`：可选的站点目录打包
- `ROLLBACK.txt`：回滚命令

## 4. 部署方案（二选一，均不动根站）

### 方案 A：8001 端口直连（最快、最少改动）

```bash
# 服务器上，确认 8001 未被占用
ss -lntp | grep ':8001' || echo "8001 free"

cd /www/wwwroot
git clone <repo-url> wolfarena   # 若已存在则跳过
cd wolfarena
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
(cd frontend && npm ci && npm run build)

./.venv/bin/python deploy/smoke.py http://127.0.0.1:8001  # 需先启动服务
```

启动（先前台跑通，再交给 systemd）：

```bash
./.venv/bin/python -m uvicorn backend.api:app --host 127.0.0.1 --port 8001
```

需要外网访问 8001 时，在云安全组和系统防火墙放行该端口。

### 方案 B：独立 vhost 反代（保留根站，推荐给评委访问）

```bash
cp deploy/nginx-wolfarena.conf /www/server/panel/vhost/nginx/wolfarena.conf
nginx -t && nginx -s reload
```

该 vhost 监听 8080，把 `/` 和 `/ws/` 全部反代到 `127.0.0.1:8001`，
WebSocket 已配置 `Upgrade`/`Connection` 与长超时。访问
`http://<server-ip>:8080/` 即可，不需要改动 80/443 的现有站点。

> 不建议使用 `/wolfarena/` 子路径：前端资源与 API 使用绝对路径，
> 子路径需要同时修改构建 base 与后端路由，属于大改，冻结期不做。

### systemd 常驻（可选）

```bash
cp deploy/wolfarena.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now wolfarena
systemctl status wolfarena --no-pager
```

`.env` 只放在服务器 `/www/wwwroot/wolfarena/.env`，权限 600，不入库、不截图。

## 5. 部署后验证

```bash
./.venv/bin/python deploy/smoke.py http://127.0.0.1:8001
./.venv/bin/python deploy/smoke.py http://<server-ip>:8080
```

`deploy/smoke.py` 会检查：

1. `GET /health` 返回 200 且 `status=ok`；
2. `GET /` 返回 HTML；
3. `POST /api/rooms` 返回 201 且有 `player_token`；
4. 玩家 `WebSocket` 认证成功（`type=authenticated`）；
5. 观战密码 `WebSocket` 认证成功；
6. 错误令牌被拒绝（返回 `type=error`）。

全部通过会输出 `ALL CHECKS PASSED`。

## 6. 回滚

```bash
# nginx 配置回滚
cp -a /www/backup/wolfarena-<时间戳>/nginx-config/. /www/server/panel/vhost/nginx/
nginx -t && nginx -s reload

# 站点目录回滚（若打包过）
tar xzf /www/backup/wolfarena-<时间戳>/site.tar.gz -C /www/wwwroot

# 停掉新服务
systemctl disable --now wolfarena
```

根站从未被覆盖，回滚只需撤销新增的 vhost 文件与服务。
