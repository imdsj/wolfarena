# AI 成长测试表 V0.1

日期：2026-10-23

基线提交：`140d650`（`feat: add auditable AI growth records and L0 policy`）

用途：验证 AI **是否真的从「不会」变成「会」**。任务单 V2.0 要求 10/24 至 10/25 完成至少 10 条成长测试，本表共 12 条，按五个维度分组。

与 `docs/07_test_cases.md` 的分工：那份测**规则是否正确**（引擎行为），本表测**AI 是否变强**（策略行为）。两者不要混用。

## 1. 判读原则（先立规矩，否则数据没意义）

| 原则 | 说明 |
| --- | --- |
| 固定种子 | 新手版与训练版对比必须使用**同一组 seed**，否则差异可能来自牌局运气而非策略 |
| 样本量 | 每次对比至少 **200 局**。200 局下胜率的标准误约 ±3.5%，小于这个幅度的差异不能算提升 |
| 只看指标不看感觉 | 「看起来更聪明」不是结论。结论必须对应一个数字：合法率、频率、胜率或人工评分 |
| 训练版必须说明版本 | 记录策略版本号或模型文件标识，否则下次无法复现 |
| 差异要能解释 | 若胜率提升但动作分布没变化，说明提升另有原因，需查清后再下结论 |

## 2. 五个维度的可测指标

| 维度 | 指标定义 | 新手版预期 | 训练版预期 |
| --- | --- | --- | --- |
| 行动合法率 | 合法动作数 ÷ 总动作数 | 存在无效目标或随机选择，合法率偏低 | 合法率显著上升，非法动作有兜底不崩 |
| 策略变化 | 各战术动作的触发频率与分布 | 无稳定战术倾向，分布接近随机 | 出现潜伏、悍跳、带票、自爆等可识别策略 |
| 胜率 | 固定 seed 下阵营胜率 | 基线低且波动大 | 同 seed 下胜率上升，波动收窄 |
| 复盘质量 | 复盘能否指出错误动作与候选策略 | 只能看出输赢 | 能定位关键转折点、成功与错误动作 |
| 可见性 | 身份、私聊、死因的可见边界 | 界面层就不该露出 | 与新手版一致，训练不得削弱权限 |

## 3. 成长测试表

「新手版实际」「训练版实际」「结论」三栏在 10/24 至 10/25 执行后填写。结论只填：提升 / 无变化 / 下降 / 阻塞。

| 编号 | 维度 | 操作步骤 | 新手版预期 | 训练版预期 | 新手版实际 | 训练版实际 | 结论 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| GT-01 | 行动合法率 | 固定 seed 跑 200 局 AI-only，统计狼队长提交的击杀目标是否均为存活玩家（含自刀白名单） | 出现指向已死玩家或无效编号的目标，合法率低于 95% | 合法率 ≥ 99%，非法目标被服务端拒绝且有兜底 |  |  |  |
| GT-02 | 行动合法率 | 统计女巫用药目标合法性：目标必须存活，同夜不得双药 | 偶发指向已死玩家或同夜双药 | 同夜双药次数为 0，目标全部合法 |  |  |  |
| GT-03 | 行动合法率 | 统计投票目标合法性：不得投已死亡玩家；弃权记为 `null` | 出现投死者或空值异常 | 全部合法，弃权正确计入 `null` |  |  |  |
| GT-04 | 策略变化 | 导出 200 局的动作分布，统计潜伏、悍跳、带票、自爆等标签的触发频率 | 无稳定标签，或标签缺失无法归类 | 各标签有明确频率，且狼/好人阵营分布合理 |  |  |  |
| GT-05 | 策略变化 | 统计自爆动作的触发次数与触发阶段 | 几乎不触发，或在不允许的阶段触发 | 触发频率非零，且全部发生在 `DAY_DISCUSSION` |  |  |  |
| GT-06 | 策略变化 | 统计狼人首夜刀人目标的角色分布（刀预言家/女巫/猎人/村民） | 目标接近均匀随机 | 明显偏向关键神职，且与胜率提升方向一致 |  |  |  |
| GT-07 | 胜率 | 同一组固定 seed，各跑 200 局，比较狼阵营与好人阵营胜率 | 基线胜率偏离 50% 较多或波动大 | 胜率变化有方向性，波动收窄 |  |  |  |
| GT-08 | 胜率 | 训练版对上一版本策略跑 200 局，比较版本间胜率 | 版本间无差异 | 新版本对小样本胜率有可解释变化 |  |  |  |
| GT-09 | 复盘质量 | 抽取 10 局失败对局，检查复盘是否指出具体错误动作 | 只说明输赢，无具体动作 | 能指出错误动作、关键转折点和候选策略 |  |  |  |
| GT-10 | 复盘质量 | 交叉核对：复盘结论与训练日志指标是否一致 | 复盘文字与数据脱节 | 结论与指标一致，无「说提升了但数据下降」 |  |  |  |
| GT-11 | 可见性 | 玩家死亡后用该账号继续浏览，抓取其收到的 WebSocket 消息 | 看不到狼人私聊、他人身份、夜间死因 | 与新手版完全一致，训练不得放宽权限 |  |  |  |
| GT-12 | 可见性 | 普通访客不输密码访问，再输入正确密码访问；检查密码是否可复用固定值 | 无密码时看不到身份 | 无密码拦截有效；每局密码独立，不存在万能密码 |  |  |  |
