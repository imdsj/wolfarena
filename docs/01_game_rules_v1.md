# WolfArena 九人局规则 V1.0

状态：第一版，关键规则已确认，可供规则引擎、界面和测试共同引用。

适用范围：P0 九人标准局，1 至 3 名真人，其余位置由 AI 补足。

维护原则：规则编号保持稳定。实现代码、接口和测试应引用规则编号，避免只依赖界面文案。

本文中的“必须”表示服务端需要强制校验，“可以”表示参与者可以选择，“不得”表示服务端必须拒绝。

## 1. 游戏配置

| 规则编号 | 配置项 | 固定值 | 服务端要求 |
| --- | --- | --- | --- |
| GAME-001 | 游戏人数 | 9 | 创建游戏时必须恰好生成 9 名玩家 |
| GAME-002 | 玩家编号 | `player_id` | 每名玩家拥有本局内唯一且不变的编号 |
| GAME-003 | 初始阶段 | `INIT` | 角色分配和狼队长确认完成后才能进入首夜 |
| GAME-004 | 真人数量 | 1 至 3 | 空余位置必须由 AI 补齐 |
| GAME-005 | 目标时长 | 约 5 分钟 | 超时规则不得改变本文件规定的胜负和行动权限 |
| GAME-006 | 身份公开 | 默认隐藏 | 只有自爆、白天猎人开枪或游戏结束时按专门规则公开 |

## 2. 角色与阵营

| 角色代码 | 中文名 | 数量 | 阵营 | 夜间能力 | 白天能力 |
| --- | --- | ---: | --- | --- | --- |
| `werewolf` | 狼人 | 3 | `wolf` | 内部讨论、由狼队长选择击杀目标、自刀或空刀 | 公开发言；讨论阶段可以自爆 |
| `villager` | 村民 | 3 | `good` | 无主动技能 | 公开发言、投票 |
| `seer` | 预言家 | 1 | `good` | 每晚查验一名存活玩家的阵营 | 公开发言、投票 |
| `witch` | 女巫 | 1 | `good` | 解药和毒药各一次，同一晚至多使用一种 | 公开发言、投票 |
| `hunter` | 猎人 | 1 | `good` | 被狼人杀死且未被救时可以开枪；被毒不能开枪 | 被投票放逐后可以开枪；公开发言、投票 |

## 3. 狼队长与狼人夜间行动

| 规则编号 | 狼人规则 |
| --- | --- |
| WOLF-001 | 首夜开始前，狼队必须从存活狼人中产生一名狼队长 |
| WOLF-002 | 三名狼人全部是 AI 时，由系统按本局 `seed` 随机选择一名狼队长 |
| WOLF-003 | 狼队中只有一名真人时，该真人自动成为狼队长 |
| WOLF-004 | 狼队中有两名或三名真人时，由真人狼人共同决定其中一人担任狼队长 |
| WOLF-005 | 真人协商狼队长时，界面同时提供“随机分配”按钮和手动选择入口；随机结果按 `seed` 可复现，手动选择时只能从真人狼人中选择 |
| WOLF-006 | 狼队长死亡后，剩余存活狼人必须在下一夜开始前按 WOLF-001 至 WOLF-005 重新确定队长 |
| WOLF-007 | 每个夜晚，每名存活狼人各进行两轮内部发言，按狼队顺序轮流进行 |
| WOLF-008 | 狼人发言对狼队和观战者可见，对其他阵营不可见 |
| WOLF-009 | 两轮讨论结束后，只有狼队长可以提交一次击杀决定 |
| WOLF-010 | 击杀决定只能是空刀、狼队长自刀或一名其他存活玩家 |
| WOLF-011 | 狼队长超时未提交决定时，本次行动按空刀处理 |
| WOLF-012 | 非狼队长提交的击杀决定必须被服务端拒绝 |
| WOLF-013 | 狼人可以在白天讨论阶段自爆，但不得在投票阶段或夜间自爆 |

狼人内部发言只提供讨论过程，不通过多数票决定击杀目标。最终刀人权限属于狼队长，其他狼人的发言和投票意向不会直接改变服务端目标。

## 4. 夜晚结算顺序

一个夜晚只生成一份最终行动结果。玩家只能看到天亮后的死亡名单，不能根据阶段变化推断每个死亡的原因。

| 顺序 | 阶段代码 | 执行者 | 允许行动 | 校验与结果 |
| ---: | --- | --- | --- | --- |
| 1 | `NIGHT_WOLF_DISCUSSION_R1` | 存活狼人 | 每名狼人发言一次 | 必须按狼队顺序完成或超时跳过 |
| 2 | `NIGHT_WOLF_DISCUSSION_R2` | 存活狼人 | 每名狼人再发言一次 | 讨论内容不直接修改刀人目标 |
| 3 | `NIGHT_WOLF_KILL` | 狼队长 | 选择空刀、自刀或一名存活玩家 | 只接受一个有效目标；超时为空刀 |
| 4 | `NIGHT_SEER_CHECK` | 存活预言家 | 查验一名其他存活玩家 | 返回该玩家属于 `wolf` 或 `good`；超时为未查验 |
| 5 | `NIGHT_WITCH_ACTION` | 存活女巫 | 不使用药、救一人或毒一人 | 同一晚不得同时使用解药和毒药 |
| 6 | `NIGHT_RESOLUTION` | 服务端 | 合并狼刀、毒药和救人结果 | 被救目标免疫本次狼刀；所有夜间死亡一次性结算 |
| 7 | `NIGHT_HUNTER_SHOT` | 符合触发条件的猎人 | 选择一名其他存活玩家或不开枪 | 夜间被狼杀且未被救的猎人可以开枪；被毒的猎人不能开枪 |
| 8 | `CHECK_WINNER` | 服务端 | 检查胜负 | 若游戏未结束，天亮并进入 `DAY_DISCUSSION` |

### 4.1 女巫用药

| 规则编号 | 女巫规则 |
| --- | --- |
| WITCH-001 | 解药整局只能使用一次，毒药整局只能使用一次 |
| WITCH-002 | 女巫同一晚最多使用一种药，不得同时救人并毒人 |
| WITCH-003 | 解药尚未消耗时，女巫在行动阶段可以看到当夜准确的狼刀目标；狼人空刀时显示没有刀口 |
| WITCH-004 | 解药已经消耗后，女巫不再获得当夜狼刀目标的信息 |
| WITCH-005 | 拥有毒药但不再拥有解药时，女巫可以毒人，但不能通过行动界面查看狼刀目标 |
| WITCH-006 | 解药可以指定任意存活玩家，包括女巫自己、狼人和被狼人自刀的目标 |
| WITCH-007 | 若解药目标当夜受到狼人击杀，该目标免疫本次狼刀；其他死因不受解药影响 |
| WITCH-008 | 解药指定了未被狼刀的目标时仍然消耗解药，但不产生额外效果 |
| WITCH-009 | 毒药可以指定任意存活玩家，包括女巫自己；被毒玩家的死因记录为 `poisoned` |
| WITCH-010 | 女巫的药在夜间统一结算，女巫当夜死亡不会撤销已经提交的有效行动 |
| WITCH-011 | 同一目标同时受到狼刀和毒药时只生成一次死亡事件，并记录两个死因 |

### 4.2 猎人触发

| 触发来源 | 是否可以开枪 | 公开处理 |
| --- | --- | --- |
| 夜间被狼人杀死且没有被救 | 可以 | 天亮只公布死亡名单，不公开猎人身份和开枪关系 |
| 夜间被女巫毒死 | 不可以 | 天亮只公布死亡名单 |
| 同时被狼刀和女巫毒死 | 不可以 | 以毒药规则为准禁止开枪 |
| 白天被投票放逐 | 可以 | 猎人遗言结束后立即公开猎人身份并开枪 |
| 狼王自爆 | 不适用九人局 | 仅在十二人实验规则中处理 |

猎人本次选择的目标必须是一名存活玩家。“不开枪”是合法选择。猎人击杀目标后立即进入死亡结算和胜负检查。

## 5. 白天流程

| 顺序 | 阶段代码 | 公开事件 | 允许行动 |
| ---: | --- | --- | --- |
| 1 | `DAY_ANNOUNCEMENT` | 公布夜间死亡名单 | 只读；不公布死因和夜间猎人身份 |
| 2 | `DAY_LAST_WORDS` | 按遗言表处理 | 符合条件者发言，最多 30 个汉字 |
| 3 | `DAY_DISCUSSION` | 存活玩家按座次轮流发言 | 每名存活玩家公开发言一次；存活狼人可在讨论期间自爆 |
| 4 | `SELF_DESTRUCT` | 触发后公布自爆者狼人身份 | 最多持续 10 秒，只允许其他存活狼人继续自爆 |
| 5 | `VOTE` | 没有发生自爆时进入投票 | 每名存活玩家提交一名玩家或弃权 |
| 6 | `DAY_HUNTER_SHOT` | 被放逐者是猎人时公开身份 | 猎人遗言后选择是否开枪；被带走者随后结算遗言 |
| 7 | `CHECK_WINNER` | 结算后检查 | 未结束则开始下一夜 |

### 5.1 公开发言

| 规则编号 | 发言规则 |
| --- | --- |
| DAY-001 | 白天公开发言只允许存活玩家参加 |
| DAY-002 | V1.0 固定进行一轮公开轮流发言，顺序按座次编号升序 |
| DAY-003 | 玩家只能在自己的回合提交发言，不得连续刷屏或抢占后续玩家的回合 |
| DAY-004 | AI 单次公开发言目标为 30 至 50 个汉字；真人发言长度由产品单独限制 |
| DAY-005 | 发言内容不得由服务端直接解释成规则动作；行动必须来自结构化请求 |

### 5.2 自爆

| 规则编号 | 自爆规则 |
| --- | --- |
| DESTRUCT-001 | 只有存活狼人可以在 `DAY_DISCUSSION` 提交自爆 |
| DESTRUCT-002 | 第一名狼人自爆后立即出局，并公开其 `werewolf` 身份 |
| DESTRUCT-003 | 自爆立即取消当天投票，阶段切换到 `SELF_DESTRUCT` |
| DESTRUCT-004 | 自爆窗口最多持续 10 秒，只允许其他存活狼人继续自爆 |
| DESTRUCT-005 | 每名自爆者依次出局、公开身份并生成公开事件 |
| DESTRUCT-006 | 自爆玩家没有遗言 |
| DESTRUCT-007 | 10 秒结束后关闭自爆入口；每次死亡都要检查胜负 |
| DESTRUCT-008 | 若狼人尚未全部出局且无其他胜者，下一次夜间阶段开始 |

## 6. 投票与放逐

| 规则编号 | 投票规则 |
| --- | --- |
| VOTE-001 | 每名存活玩家拥有一票，可以投给任意存活玩家，包括自己 |
| VOTE-002 | 玩家可以弃权；弃权记为 `null`，不计入任何候选人的票数 |
| VOTE-003 | 玩家在同一投票阶段可以更新自己的最终选择，服务端以截止前的最后一次有效提交为准 |
| VOTE-004 | 得票数唯一最高的玩家被放逐 |
| VOTE-005 | 所有玩家均为零票时无人出局 |
| VOTE-006 | 最高票并列时无人出局，不进行第二轮投票或加赛 |
| VOTE-007 | 投票结束后先处理被放逐者遗言；若被放逐者是猎人，随后进入猎人开枪 |
| VOTE-008 | 猎人开枪带走的目标在死亡后获得遗言，再执行下一次胜负检查 |

## 7. 死亡处理与遗言

“白天公开死亡”包括投票放逐和白天猎人开枪；“夜间死亡”包括狼刀、毒药和夜间猎人开枪。

| 死亡情形 | 是否有遗言 | 身份是否公开 | 说明 |
| --- | --- | --- | --- |
| 第 1 天夜晚死亡 | 有 | 否 | 天亮后按死亡名单顺序发言，每人最多 30 个汉字 |
| 第 1 天投票放逐 | 有 | 否 | 投票结果公布后发言，最多 30 个汉字 |
| 第 2 天及以后发生夜间死亡 | 无 | 否 | 只公布死亡名单 |
| 第 2 天及以后投票放逐 | 有 | 否 | 投票放逐始终保留公开遗言 |
| 白天被猎人开枪带走 | 有 | 猎人身份公开，被带走者身份不公开 | 猎人先完成自己的遗言和开枪，再由被带走者发言 |
| 夜间被猎人开枪带走 | 仅第 1 天有 | 否 | 夜间只公布最终死亡名单，不公开猎人身份 |
| 狼人自爆 | 无 | 是 | 立即公开 `werewolf` 身份 |

死亡事件必须记录 `player_id`、`day`、`phase`、`causes`、`event_seq` 和 `visibility`。同夜多人死亡时，公开界面一次性显示完整死亡名单，但在服务端内部保留独立的死亡原因。

## 8. 胜负条件

| 规则编号 | 条件 | 结果 | 检查时机 |
| --- | --- | --- | --- |
| WIN-001 | 存活狼人数量为 0 | 好人阵营胜利 | 任一次死亡结算后 |
| WIN-002 | 存活狼人数量大于或等于存活好人数量 | 狼人阵营胜利 | 任一次死亡结算后 |
| WIN-003 | 两个条件均不满足 | 游戏继续 | 进入下一阶段 |
| WIN-004 | 同一次结算同时满足两个条件 | 好人阵营胜利 | 按 WIN-001 优先 |

胜负检查至少发生在以下时点：

1. 夜间死亡批次结算后。
2. 夜间猎人开枪并产生死亡后。
3. 每名自爆狼出局后。
4. 白天投票放逐后。
5. 白天猎人开枪并产生死亡后。

游戏进入 `END` 后冻结全部行动，记录胜者与结束原因，并向所有玩家公开身份、死亡原因和关键夜间事件。

## 9. 服务端事件

| 事件代码 | 触发者 | 关键字段 | 默认可见范围 |
| --- | --- | --- | --- |
| `GAME_CREATED` | 系统 | `game_id`, `seed`, `players` | 服务端 |
| `ROLE_ASSIGNED` | 系统 | `player_id`, `role` | 本人和观战者 |
| `WOLF_CAPTAIN_ELECTED` | 狼队 | `captain_id`, `day` | 狼队和观战者 |
| `WOLF_SPEECH` | 存活狼人 | `actor_id`, `round`, `content` | 狼队和观战者 |
| `WOLF_KILL_SELECTED` | 狼队长 | `actor_id`, `target_id`, `kill_type` | 狼队和观战者 |
| `SEER_CHECKED` | 预言家 | `actor_id`, `target_id`, `result` | 预言家和观战者 |
| `WITCH_USED_ANTIDOTE` | 女巫 | `actor_id`, `target_id` | 女巫和观战者 |
| `WITCH_USED_POISON` | 女巫 | `actor_id`, `target_id` | 女巫和观战者 |
| `PLAYER_DIED` | 系统 | `player_id`, `causes`, `phase` | 按死亡公开规则 |

| `WINNER_DECIDED` | 系统 | `winner`, `reason` | 所有人 |

`PLAYER_DIED.causes` 使用以下固定值：

| 原因代码 | 中文含义 |
| --- | --- |
| `wolf_kill` | 被狼人击杀 |
| `poisoned` | 被女巫毒杀 |
| `hunter_shot` | 被猎人开枪带走 |
| `banished` | 被投票放逐 |
| `self_destruct` | 狼人自爆 |
