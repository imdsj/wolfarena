# L1 规则策略工程对照

代码提交：`25e95e8`

策略标识：`l1.rule.v1`

性质：确定性规则策略，不是 Q-learning，不是训练版。

## 实现规则

- 有公开发言时优先完成正常发言，不随机选择可选自爆。
- 狼人存在公开自报神职目标时优先刀该目标；没有自报时选择当前合法目标首位。
- 预言家优先查验自己尚未查验的存活目标。
- 女巫仍有解药且刀口在当前合法目标中时使用解药；否则不使用药。
- 所有动作、目标和选项仍经过统一服务端校验。

## 同 seed 对照

两版都运行 seed 1000 至 1199，各 200 局：

| 指标 | L0 随机 | L1 规则 |
| --- | ---: | ---: |
| 完成局 | 200 | 200 |
| 失败局 | 0 | 0 |
| 动作数 | 8719 | 15403 |
| 行动合法率 | 100% | 100% |
| 好人胜局 | 168 | 73 |
| 狼人胜局 | 32 | 127 |
| 平均步数 | 43.595 | 77.015 |
| 平均单局耗时 | 15.099815 ms | 34.148625 ms |

同 seed 中，125 局结局发生变化，75 局结局相同。

L1 的狼人胜率更高不代表 AI 学习后变强。两者只是不同的人工规则，且 L1 的狼人
目标规则可能明显改变样本分布。G-06 训练前后对照依然为 No-Go。
