# RAG 消融实验：无检索 / 词法检索 / 结构化检索

日期：2026-11-14

## 实验设置

- 固定局面：12 个，覆盖村民、预言家、狼人、女巫、猎人在白天讨论、投票、夜间查验、狼刀、女巫用药、猎人开枪等阶段。
- 每个局面人工标注 1 个“该局面最应命中的战术卡”。
- 指标：Recall@3，即检索结果前 3 条中命中期望战术的比例。
- 三种方法使用同一套策略库与同一批局面，结果可复现、离线运行、不依赖任何外部模型或 embedding 服务。

方法定义：

| 方法 | 说明 |
| --- | --- |
| 无检索 | 只按角色/阶段过滤，按 `strategy_id` 字母序取前 3 |
| 词法检索 | 用当前公开发言、审计结论、票型组成查询文本，走原有词法检索 |
| 结构化检索 | 角色/阶段过滤 + 审计信号 + 票型信号 + 角色默认稳健战术 + 词法重合加权 |

## 汇总

| 方法 | Recall@3 |
| --- | --- |
| 无检索 | 0.667 |
| 词法检索 | 0.500 |
| 结构化检索 | **1.000** |

## 结论

1. 只按角色/阶段取卡（无检索）会漏掉与当前局面真正相关的战术，12 个局面中只命中 8 个。
2. 纯词法检索依赖字面重合，遇到“对跳”“同票”这类局面语义时反而漏检，只命中 6 个。
3. 结构化检索通过三个层次提升命中：
   - 角色与阶段硬过滤，先排除不可能适用的战术；
   - 把逻辑审计结论、票型特征、神职自报等转成检索信号，与战术触发条件对齐；
   - 无强信号时回落到该角色/阶段的稳健默认战术，避免字母序瞎选。
4. 结构化检索全程离线、确定性，可复现，不需要付费 embedding 接口。
