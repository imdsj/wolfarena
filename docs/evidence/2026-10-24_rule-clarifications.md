# 2026-10-24 白天规则口径确认

日期：2026-10-24

功能提交：`dc2a30a`（`fix: align vote, hunter, and last-word visibility rules`）

固定超时补充提交：`806bec3`（`fix: enforce fixed public speech timeout`）

这是需要同步给全体开发成员的新口径。

## 1. 自爆窗口

- 窗口最长10秒。
- 只有当前时间小于截止时间时仍可自爆。
- 到达10秒边界立即关闭，不再接受自爆。

## 2. 公开发言超时

- 每名玩家固定30秒。
- 发言完成或超时后推进。
- 使用服务端传入的时间判断，不使用客户端时间。

## 3. 投票

- 投票期间不公开具体票型。
- 服务端和观战者保留内部 `VOTE_CAST` 审计记录。
- 投票结束后生成公开 `VOTE_RESULT`。
- `VOTE_RESULT` 包含每名存活玩家的最终选择、弃权、票数汇总和是否放逐。
- 修改投票时只公开最后有效选择。
- 未投票玩家按弃权处理。
- 全员弃权或最高票并列时无人出局。

## 4. 遗言长度

- 每条遗言最多100个汉字。
- 标点、数字和表情不计入汉字数量。
- 服务端负责校验，不能只依赖前端。
- 原30字口径已废止。

## 5. 猎人身份

- 玩家死亡不会自动翻牌身份。
- 夜间猎人开枪关系只对猎人和观战者可见。
- 白天猎人开枪后公开猎人身份。
- 白天猎人选择不开枪时不公开猎人身份。
- 只有自爆按规定公开狼人身份。

## 6. 验收结果

```text
Ran 89 tests in 0.017s

OK
```

新增或更新的测试覆盖：

- 100个汉字通过、101个汉字拒绝。
- 标点不计入汉字数量。
- 投票过程中普通玩家看不到具体票型。
- 投票结算后 `VOTE_RESULT` 公开最终票型。
- 白天猎人不开枪时身份对普通玩家隐藏。
- 10.0秒边界拒绝新的自爆。
