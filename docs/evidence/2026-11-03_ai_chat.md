# AI 对话能力 · 2026-11-03

## 能力

`POST /api/rooms/{room_id}/chat`：玩家在房间里对某个 AI 座位说一句话，
AI 用 DeepSeek 基于**公开信息**回一句。它不改游戏状态，不影响发言顺序和投票。

请求：

```json
{"message": "你好，你觉得几号最可疑？", "seat": 2}
```

`seat` 可省略，默认取第一个存活 AI 座位。响应：

```json
{"room_id": "...", "seat": 2, "name": "玩家2", "reply": "...", "source": "deepseek"}
```

## 安全边界

- 提示词只含：目标座位号、天数、阶段、存活玩家的“座位号+昵称”、最近 3 条
  `PUBLIC_SPEECH`、玩家这句话。**不含任何人的真实身份、不读狼聊、不读环境变量。**
- 系统提示要求：只用公开信息、不编造他人身份、不承认自己是 AI、不输出密钥。
- 每房间 3 秒限流；消息最长 200 字；无 Key、超时或异常时回退到模板回复。
- 回复只进入对话面板，不写入对局事件，不改变胜负判定。

## 验证

- 本地测试 261 项通过（新增 5 项：模型回复、失败降级、提示词不含身份、
  限流 429、无 token 401 / 超长 422）。
- 公网服务器实测（`9feb91a`）：`status 200`、`source deepseek`，
  回复“目前还没发言，看不出谁可疑，先听听大家怎么说再判断。”

## 限制

- 这是一句一答的旁路对话，不保存上下文记忆，不做多轮推理。
- AI 的正式发言仍由规则模板生成，接入 LLM 的发言只在对话面板。
- 依赖服务器 `.env` 的 `DEEPSEEK_API_KEY`；未配置时全部走模板兜底。
