### 训练曲线（每 50 局一段，共 20 段）

| 指标 | 前一半 | 后一半 | 变化 |
| --- | ---: | ---: | ---: |

首段平均奖励 `+0.017`，末段 `-0.112`；平均 |TD 误差| 从 `0.0582`
降到 `0.0492`（−15%）。

判定：**训练过程稳定但未收敛到提升**。没有发散，也没有非法动作，
但终局奖励没有随训练变好，|TD 误差| 只小幅下降。原因可解释：
奖励是终局稀疏信号，九个座位共用一个 Q 表，且对手（L0/L1 混合规则）
在同一批次内同步变化，状态空间只覆盖 199 个离散键。
因此**不得**把这一段写成本项目“已收敛”或“学到更优策略”。

## 4. 复现命令

```powershell
# 训练（seed 0–999）
python -m backend.simulator --games 1000 --seed-start 0 --policy l2 `
  --out training_runs/train-l2-0000-0999 `
  --model-out strategy_library/models/l2-qtable-v1.json --commit b1234e9

# 评估（seed 1000–1199，加载后 freeze，epsilon=0）
python -m backend.simulator --games 200 --seed-start 1000 --policy l2 `
  --model-in strategy_library/models/l2-qtable-v1.json `
  --out training_runs/eval-l2-200 --commit b1234e9

python -m backend.simulator --games 200 --seed-start 1000 --policy l0 `
  --out training_runs/eval-l0-200 --commit b1234e9

python -m backend.simulator --games 200 --seed-start 1000 --policy l1 `
  --out training_runs/eval-l1-200 --commit b1234e9

python -m backend.metrics --run training_runs/eval-l2-200
```

`--model` 与 `--model-in` 等价，已在 README 注明。
