# WolfArena 夜间行动引擎 V0.1

状态：服务端夜间权威规则已实现并通过自动化测试。

代码位置：`backend/game_engine.py`

规则来源：`docs/01_game_rules_v1.md`

## 1. 夜间阶段

```text
INIT
→ NIGHT_WOLF_DISCUSSION_R1
→ NIGHT_WOLF_DISCUSSION_R2
→ NIGHT_WOLF_KILL
→ NIGHT_SEER_CHECK
→ NIGHT_WITCH_ACTION
→ NIGHT_RESOLUTION
→ NIGHT_HUNTER_SHOT
→ DAY_ANNOUNCEMENT
```

已经死亡的预言家或女巫会被自动跳过。猎人有开枪资格时，`resolve_night` 停在 `NIGHT_HUNTER_SHOT`；本版本只记录资格，尚未实现猎人选择目标和开枪。

## 2. 服务端接口

| 函数 | 输入 | 输出 | 当前职责 |
| --- | --- | --- | --- |
| `elect_wolf_captain` | 状态、可选队长编号 | 更新后的状态 | 从存活狼人中产生队长 |
| `record_wolf_speech` | 状态、狼人编号、轮次、内容 | 更新后的状态 | 记录两轮有序狼人发言 |
| `select_wolf_kill` | 状态、狼队长编号、目标编号或 `None` | 更新后的状态 | 记录唯一狼刀决定 |
| `submit_seer_check` | 状态、预言家编号、目标编号 | `Team.WOLF` 或 `Team.GOOD` | 查验阵营并写入私有事件 |
| `get_witch_kill_target` | 状态、女巫编号 | 刀口编号或 `None` | 按解药持有状态返回女巫可见刀口 |
| `submit_witch_action` | 状态、女巫编号、动作、目标 | 更新后的状态 | 提交救人、毒人或不用药 |
| `resolve_night` | 状态 | 更新后的状态 | 合并死亡、隐藏死因并检查胜负 |
| `get_visible_events` | 状态、玩家或观战者 | 事件元组 | 按视角过滤和脱敏事件 |

玩家动作统一按以下顺序校验：

```text
玩家身份
→ 玩家存活
→ 当前阶段
→ 动作目标
→ 写入事件
→ 必要时检查胜负
```

校验失败时不得写入事件，也不得修改狼刀、药品、死亡或阶段状态。

## 3. 狼队长

- 全 AI 狼队使用 `seed + day` 可复现地随机选择。
- 只有一名真人狼人时，该真人自动成为队长。
- 多名真人狼人时必须从真人中选择；不传队长编号时使用可复现随机结果。
- 非狼人、死亡狼人和非真人候选在存在真人狼人时会被拒绝。
- 存活的现任队长已存在时不能重复选择。
- 队长事件只对存活狼队和观战者可见。

## 4. 狼人发言与狼刀

- 存活狼人必须按座位顺序完成第一轮发言，然后按同一顺序完成第二轮。
- 每名狼人每轮只能发言一次。
- 非狼人、死亡狼人、错误轮次和错误阶段均会失败。
- 两轮发言结束后阶段自动进入 `NIGHT_WOLF_KILL`。
- 只有狼队长可以提交狼刀，而且整夜只能提交一次。
- 合法的狼刀决定包括空刀、自刀和击杀一名其他存活玩家。
- 目标已经死亡时拒绝提交。

## 5. 预言家

- 只有存活的预言家可以提交查验。
- 查验目标必须存活，且不能是预言家自己。
- 返回结果为 `wolf` 或 `good`。
- `SEER_CHECKED` 事件只对预言家本人和观战者可见。
- 查验完成后，若女巫存活则进入 `NIGHT_WITCH_ACTION`，否则进入 `NIGHT_RESOLUTION`。

## 6. 女巫

合法的 `action` 值：

| 动作 | 目标 | 效果 |
| --- | --- | --- |
| `antidote` | 任意存活玩家 | 消耗唯一解药 |
| `poison` | 任意存活玩家 | 消耗唯一毒药 |
| `none` | 不得指定目标 | 不消耗药 |

- 同一夜只能提交一次女巫行动。
- 可以使用已经消耗的解药或毒药时立即拒绝。
- 解药可以救女巫本人或其他任何存活玩家。
- 解药指定未被狼刀的目标时仍然消耗。
- 解药未消耗时，`get_witch_kill_target` 返回准确狼刀目标；解药消耗后返回 `None`。
- 狼人空刀时，即使女巫持有解药也返回 `None`。
- 女巫用药事件只对女巫本人和观战者可见。

## 7. 夜间结算

`resolve_night` 只在 `NIGHT_RESOLUTION` 阶段执行，并要求：

- 狼队长已经提交狼刀。
- 存活女巫已经提交 `antidote`、`poison` 或 `none`。
- 本夜尚未结算。

结算规则：

1. 狼刀命中目标且目标不是解药对象时记录 `wolf_kill`。
2. 毒药目标记录 `poisoned`。
3. 同一目标可以同时记录两个死因，但只生成一条 `PLAYER_DIED` 事件。
4. 按座位编号生成稳定死亡名单。
5. 玩家在游戏中只看到死亡玩家，不能看到 `causes`；观战者和游戏结束后可以看到死因。
6. 猎人因狼刀死亡且没有被毒时，设置 `hunter_can_shoot=True`。
7. 猎人被毒，或被狼刀和毒药同时命中时，不能开枪。
8. 没有猎人等待开枪时立即检查胜负；否则停在 `NIGHT_HUNTER_SHOT`。
