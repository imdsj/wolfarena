## 1. 项目是什么

WolfArena（狼域），第九届传智杯 AI Web 开发挑战赛 B 组项目。

一句话定位：把**九人狼人杀**、**可解释的 AI Agent 行为**、**可复现的策略训练**放在同一个 Web 平台里。

比赛要现场证明的核心点：

- 九个 AI 座位是**九个独立 Agent**，不是同一个策略换角色提示词
- 四种人格（冲锋 / 稳健 / 逻辑 / 搅局）真实改变目标选择、发言和战术使用
- Agent 能规划、调用白名单工具，并用事件证据解释决策
- RAG 有来源、有检索过程、有消融对照
- 战术能提交、训练、评测、审批、回滚
- 观战与赛后能看懂 AI 为什么这样行动

### 4.4 模拟器与训练

```powershell
# 全 AI 对局，10 局
python -m backend.simulator --games 10 --seed-start 1000 --policy l0 --out training_runs/smoke-l0 --commit 1c47c2e

# L2 Q-learning 训练 + 独立 seed 评估
python -m backend.simulator --games 20 --seed-start 0 --policy l2 --out training_runs/l2-train-20 --model-out training_runs/l2-train-20/model.json --commit 1c47c2e
python -m backend.simulator --games 20 --seed-start 1000 --policy l2 --out training_runs/l2-eval-20 --model-in training_runs/l2-train-20/model.json --commit 1c47c2e
```

训练 seed 与评估 seed **必须不重叠**。20 局样本只能证明流程跑通，不能声称胜率提升。

## 7. 设计约束（改代码前必读）

1. **模型不能改游戏状态。** 只生成候选，服务端 `available_actions` 校验通过才进引擎。
2. **不能读他人隐藏身份。** 检索和工具只读当前玩家可见信息。
3. **不能选服务器没给的目标。** 非法动作记 `AI_ACTION_FAILED` 并回滚。
4. **同 seed + 同动作序列 = 同 AI 事件序列。** 实时房 seed 由服务端生成，浏览器不许用 `Date.now()`。
5. **`.env` 永不入库。** 真实 Key 只写本地和服务器，`.env.example` 只放变量名。
6. **房间数据在进程内存。** 服务重启即清空，不要假设持久化。
7. **房间号区分大小写。** 不要擅自转大小写。

## 9. 成本控制（上一轮踩的坑）

上一轮 Codex 会话把上下文滚到 **1.76 亿 input token**，原因是：

- 单个会话跨两天持续使用，累积 3351 条记录
- 每轮请求都把 48.5 万 token 的完整历史重发给模型
- 21 个用户回合触发 186 次模型调用（每个回合 8~9 步工具调用）

**接手后的做法：**

1. **一个任务一个会话。** 部署完就开新会话做下一件事，不要在一个会话里连续干一整天。
2. **长任务拆成短会话。** 大重构分多次，每次独立会话，靠 `docs/` 和 git commit 传递上下文，不靠聊天历史。
3. **`model_reasoning_effort` 用 medium 就够**，不必 high。
4. **项目自带 `llm_budget.py`**（进程级花费台账），夜间训练前先确认预算上限。
5. **搜索类工具单次输出上限不要开到 30000 token**，5000 足够。

判断标准：如果界面顶部的上下文用量条过半，就该开新会话了。
