# WolfArena 白天引擎 V0.1

状态：服务端白天主链已实现并通过自动化测试。

代码位置：`backend/game_engine.py`

规则来源：`docs/01_game_rules_v1.md` 第 5 至 8 章。

## 1. 白天状态机

```text
NIGHT_HUNTER_SHOT（可选）
→ DAY_ANNOUNCEMENT
→ DAY_LAST_WORDS（存在遗言时）
→ DAY_DISCUSSION
→ SELF_DESTRUCT（发生自爆时）
或 → VOTE（未自爆时）
→ DAY_HUNTER_SHOT（被放逐者是猎人时）
→ 下一夜或 END
```

## 2. 数据模型

`GameState` 增加 `day_result`，由 `DayResult` 保存：

- 当日公布死亡名单。
- 遗言队列及已完成遗言。
- 公开发言顺序和当前位置。
- 自爆玩家及窗口截止时间。
- 每名玩家最后一次有效投票。
- 被放逐玩家。
- 白天猎人开枪状态。
- 当日死亡原因。
- 遗言结束后的目标阶段。
- 当日是否已结算。

新增事件：

```text
PUBLIC_SPEECH
LAST_WORDS
```

## 4. 关键规则

### 遗言

- 第1天夜间死亡按死亡名单顺序获得遗言。
- 第2天及以后夜间死亡没有遗言。
- 投票放逐任何一天都有遗言。
- 白天被猎人带走的目标有遗言。
- 自爆玩家没有遗言。
- 每条遗言最多100个汉字；标点、数字和表情不计入汉字数量。

### 公开发言

- 只能由存活玩家发言。
- 只能按存活玩家座位顺序进行。
- 每人一轮且只能提交一次。
- 全员完成后进入投票。
- 狼人可以在讨论阶段任意时刻自爆。
- 发言期限由调用方传入服务端时间；未到截止时间不能跳过。
- 超时会记录 `PUBLIC_SPEECH_TIMEOUT`，并推进到下一名存活玩家。

### 自爆

- 第一次自爆立即取消投票并公开狼人身份。
- 自爆窗口从当前时间起持续最多10秒。
- 时间由调用方传入，单元测试不真实等待。
- 窗口内只允许其他存活狼人自爆。
- 每次自爆死亡后立即检查胜负。
- 窗口关闭后进入下一夜；死亡队长会在 `start_night` 前自动重选。

### 投票

- 只能由存活玩家提交。
- 可以投自己，也可以弃权。
- 改票时保存最后一次有效选择。
- 投票进行中不公开具体票型。
- 投票结束后通过 `VOTE_RESULT` 一次性公开每名存活玩家的最终选择。
- 所有零票或最高票并列时无人出局。
- 唯一最高票玩家被放逐。
- 未提交的玩家在结算时视为弃权。

### 猎人

- 夜间被狼刀且未被毒时进入夜间猎人阶段。
- 夜间开枪事件只对猎人和观战者可见。
- 白天被投票放逐的猎人先留遗言，再开枪。
- 白天开枪和被带走者死亡公开。
- 白天猎人不开枪时，不向普通玩家公开其身份。
- 被带走者先完成遗言，再检查是否进入下一夜。

## 5. 当前边界

- 尚未接入真实 WebSocket 定时器。
- 公开发言超时规则已经实现，但实际倒计时触发仍需 WebSocket 或任务调度器调用。
- 自爆窗口也使用调用方传入的服务端时间。
- 前端没有播放动画或展示面板。
- 尚未实现 AI 自动选择白天动作。
- 200局成长对比仍为阻塞，直到完整自动对局与动作日志导出接入。
